# Contributing to Silverside

Thank you for your interest in Silverside. Bug reports, ideas, and pull
requests are welcome. For a large change, open an issue first, so that we can
talk about it before you do the work.

## Before you send a change

- Run `make format`, `make lint`, and `make test`. Lint must be clean.
- Add a line to [CHANGELOG.md](CHANGELOG.md) when you change what people see
  or can do.
- Talk with us before you add an outside dependency.
